با نام و یاد خدا
برای کار با بک اند و فرانت اند به طور همزمان فرایند زیر را انجام دهید

ابتدا پکیج های هر دو بخش را اینستال کنید
npm install

سپس در دو ترمینال جداگانه فایل ها را ران کنید

فرانت اند
npm run dev

بک اند
node backend/server.js

پس از اجرا میتوان با درخواست فرستادن به اندپوینت های زیر کار انجام داد.

تکنولوژی استفاده شده در بک اند express و express-session است.
سکرت و uri دیتابیس در فایل کانفیگ در پوشه کانفیگ است
دیتابیس استفاده شده mongodb و کتابخانه mongoose است.

در برنامه cors نیز فعال است تا بک اند و فرانت اند بتوانند با پورت های مختلف ارتباط برقرار کنند.
همچنین میدلور استاتیک برای کاربا فایل های استاتیک در صورت نیاز ایجاد شده است.


auth endpoints

GET /auth/register (optional)
نمایش صفحه ثبت نام (اختیاری)

GET /auth/login (optional)
نمایش صفحه ورود (اختیاری)

POST /auth/register
عملیات ثبت نام

مقدار های زیر در بادی درخواست ارسال شوند.
email (required)
password (required)
name (required)
role (required) فقط دو مقدار admin و user قابل پذیرش است

این اندپوینت ابتدا بررسی میکند که آیا ایمیل وجود دار یا نه اگر موجود نبود اجازه ثبت نام میدهد و سشن برای کاربر ایجاد میکند و به /dashboard ریدایرکت میکند
در هنگا ثبت نام یک یوزر آیدی برای یوزرها ساخته میشود که بعدا میتوان از ان استفاده کرد

POST /auth/login
عملیات ورود

مقدار های زیر در بادی درخواست ارسال شوند.
email (required)
password (required)
اندپوینت بررسی میکند آیا این ایمیل وجود دارد در صورتی وجود نداشت پیام خطا میفرستد و در صورت وجود نداشتن سشن برای کاربر میسازد و به /dashboard ریدارکت میکند

POST /auth/logout
عملیات خروج
سشن کاربر را حذف میکند و به /auth/login ریدایرکت میشود.




dashboard endpoints
این اندپوینت ها توسط میدلور isAdmin بررسی میشوند که آیا ادمین وارد شده است یا نه در صورتیکه ورودی انجام نشده باشد به /auth/login ریدایرکت میشود و در صورتیکه یوزر ادمین نباشد با پیام خطا مواجه میشود. فقط ادمین ها دسترسی به روت های زیر را دارند.

GET /dashboard
نمایش داشبورد 

GET /dashboard/products
دریافت لیست محصولات
شامل نام - تعداد - پروداکت آیدی - توضیحات

GET /dashboard/productDetails/:productID
دریافت جزییات اطلاعات محصول
در پارامتر مقدار productID را به یو آر ال پاس بدهید

POST /dashboard/product
ایجاد محصول
در بادی درخواست مقدار های زیر را پاس بدهید
name (required)
description
count (required)
پس از ارسال مقدار productID به طور خودکار ست خواهد شد

این اندپوینت ابتدا بر اساس نام بررسی میکنم که آیا محصول هست یا نه در صورتی که وجود داشته باشد خطا میدهد و در صورت نبود خطا پیام موفقیت ارسال میکند.

PUT /dashboard/product/:productID
ویرایش محصول
پروداکت آیدی را به یو آر ال حتما پاس دهید
در بادی درخواست این موارد را ارسال کنید
name (required)
description
count (required)

پس ازانجام ویرایش پیام موفقیت دریافت میکنید

DELETE /dashboard/product/:productID
حذف محصول
پارامتر productID را به یو آر ال پاس دهید
در وصرتی که محصول موجود باشد حذف انجام میشود

GET /dashboard/users
دریافت کاربران

GET /dashboard/userDetails/:userID
دریافت جزییات اطلاعات کاربر
مقدار userID را به پارامتر پاس دهید

PUT/dashboard/user/:userID
ویرایش کاربر
پارامتر userID را به یو آر ال پاس دهید
در بادی مقادیر زیر را ارسال کنید

email (required)
name (required)
role (required) فقط دو مقدار admin و user قابل پذیرش است
در صورتی که ایمیل موجود باشد ویرایش انجام میشود

DELETE /dashboard/user/:userID
حذف کاربر
پارامتر userID را به یو آر ال پاس دهید
در صورتی که userID موجود باشد کاربر حذف میشود و مجبور به ثبت نام دوباره است

نکته: متدی با عنوان ایجاد کاربر اضافه نکردم به این علت که یدر یک پروژه واقعی این مضوع منطقی نیست اما در صورت نیاز اطلاع دهید براتون ایجاد میکنم.
